Vom Konsultationsgespräch zum Repository-Zugriff in 72 Stunden.

Das niogod™ Einsatz-Protokoll ist ein dokumentiertes vierphasiges Bereitstellungsverfahren, gestützt auf einen fünfstufigen Pilot-Engineer-Vetting-Algorithmus. Das ist keine Marketing-Geschwindigkeit — es ist operative Rigorosität.

Durchschnittliche Time-to-Code: 2.8 Tage

// 01

Die vier Phasen.

Jede Phase ist durch ein explizites Übergabeartefakt geregelt. Die Uhr beginnt mit der unterzeichneten NDA.

// T+0h · Konsultation & Scoping

30-minütiges Gespräch. Unterzeichnete NDA. Einsatzbriefing erfasst.

Eine 30-minütige strukturierte Konsultation mit dem DACH Liaison. Wechselseitige NDA via eIDAS QES unterzeichnet. Problemstellung, Ziel-Stack, Vertikale und Team-Schnittstelle werden in einem strukturierten Einsatzbriefing erfasst — einem einzigen Artefakt, mit dem der Senior Consultant arbeitet.

Verantwortlich: DACH Liaison. Mandant-Aufwand: 30 Minuten.

// T+12h · Pod-Konfiguration

Senior Consultant gematcht. Projektleiter zugewiesen. Pilot Engineer ausgewählt.

Der Senior Consultant wird passend zum Stack und Mandantenkontext aus der niogod™-Bench ausgewählt. Der Projektleiter wird zugewiesen. Der Pilot Engineer wird aus dem aktiven Tier-1-Pool selektiert. Die Pod-Komposition wird dem Mandanten zur Prüfung mit Rollenprofilen, Qualifikationen und Vorarbeitgeber-Archetypen vorgelegt.

Verantwortlich: Projektleiter + Senior Consultant. Mandant-Aufwand: Profilprüfung (~30 Min.).

// T+24h · Vertragswerk

Werkvertrag, AVV, NDA, IP-Assignment via eIDAS QES.

Das vollständige Vertragswerk — Werkvertrag (BGB §631 ff.), Auftragsverarbeitungsvertrag (Art. 28 DSGVO), wechselseitige NDA, IP-Assignment — wird finalisiert und via Qualifizierter Elektronischer Signatur (eIDAS) gegengezeichnet. Die Rechtsberatung des Mandanten kann an einem 30-minütigen Counsel-to-Counsel-Gespräch vor Unterschrift teilnehmen.

Verantwortlich: DACH Liaison + Mandanten-Rechtsberatung.

// T+48h · Onboarding

Repository-Zugriff. Ticketsystem-Integration. Sicherheits-Review.

Repository, Ticketsystem (GitHub/GitLab/Linear/Jira) und Kommunikationskanäle werden bereitgestellt. Der Pod absolviert das Sicherheits-Review gegen die Posture des Mandanten. Ein Kick-off-Meeting mit der Geschäftsführung bestätigt Deliverable-Umfang und Abnahme-Kriterien.

Verantwortlich: Projektleiter. Mandant-Aufwand: Bereitstellung + Kick-off-Teilnahme.

// T+72h · Operativer Einsatz

Erste Sprint-Commits. Statusbericht-Kadenz fixiert.

Der Pod beginnt mit der Lieferung. Tägliche async Statusbericht vom Projektleiter an den Mandanten-CTO. Wöchentliches 30-minütiges Steering-Gespräch. Monatlicher schriftlicher Statusbericht mit KPIs, Risikoregister und Aufwandsbericht. Quartalsweises Senior-Consultant-Architektur-Review.

Verantwortlich: Projektleiter (Lieferung) + Senior Consultant (Architektur).

// 02

Der fünfstufige Vetting-Algorithmus.

Auf jeden Pilot Engineer vor Platzierung angewendet. End-to-End-Akzeptanzquote: <1 %.

// Stufe 1 · Sourcing-Pool

Tier-1-Alumni-Netzwerke der indischen Spitzeninstitutionen.

Profile indexiert über IIT-, BITS-, IIIT-, NIT-, ISI-, IISc-Alumni-Netzwerke und Corporate-Alumni-Netzwerke (ex-Bosch India, ex-Siemens India, ex-SAP Labs, ex-Mercedes Benz R&D India).

// Stufe 2 · Algorithmischer Vorfilter

Stack-Match, schriftliche Kommunikation, Zeitzonen-Überlappung.

Filterung nach Mandanten-Stack und Seniority-Signalen. C1+ schriftliches Englisch zwingend. CET-Überlappungsfenster von 3,5–4,5 Stunden erforderlich. Arbeitsdeutsch (A2+) als starker Pluspunkt markiert.

// Stufe 3 · Technisches Assessment

Pair-Coding, System-Design-Interview gegen Deep-Tech-Case.

Ein 90-minütiges technisches Assessment mit einem niogod™-Senior-Engineer: Pair-Coding an einer repräsentativen Produktivaufgabe, System-Design-Interview gegen einen Deep-Tech-Case aus der Vertikale des Mandanten.

// Stufe 4 · Senior-Consultant-Review

Domänen-Fit-Gate.

Der vertikal-passende Senior Consultant beurteilt Domänen-Fit, Produktiv-Erfahrung und Engineering-Urteilsvermögen unter Mehrdeutigkeit. Diese Stufe hat die höchste Filterquote.

// Stufe 5 · Projektleiter-Culture-Fit-Gate

Arbeitsweise, schriftliche Kommunikationsklarheit, Eskalationsverhalten.

Letztes Gate: der Projektleiter beurteilt Arbeitsweise unter DACH-Kadenz, schriftliche Kommunikationsklarheit und Eskalationsverhalten. Dieses Gate schützt den Mandanten vor Kommunikationsfriktion.

// 03

Governance-Kadenz.

Jede Kadenz ist im Werkvertrag vertraglich definiert. Keine Überraschungs-Rituale.

// Täglich

Async Statusbericht

Vom Projektleiter an den Mandanten-CTO. Gestern, heute, Blocker, Risikoregister-Updates.

// Wöchentlich

30-min. Steering-Gespräch

Projektleiter + Senior Consultant + Mandanten-CTO. Sprint-Review, Prioritäten, Eskalationspfade.

// Monatlich

Schriftlicher Statusbericht

KPIs, Risikoregister, Aufwandsbericht, Abnahme abgeschlossener Werke.

// Quartalsweise

Architektur-Review

Senior-Consultant-geleitetes Architektur-Review mit Mandanten-CTO. Refresh des vertikalen Mandantenkontexts.

// 04

Wir arbeiten in Ihrem Stack.

Kein proprietäres niogod™-Tooling erforderlich. Der Pod adaptiert sich an Ihren Stack — nicht umgekehrt.

// Source & Tickets

GitHub, GitLab, Linear, Jira, Notion. SSO via Ihre IdP. Audit-Log-Zugriff für den Mandanten.

// Kommunikation

Slack, Microsoft Teams, Mattermost. Der Projektleiter ist der einzige Mensch, den Sie pingen; der Pilot Engineer ist über den Pod-Channel erreichbar.

// Hosting & Daten

AWS Frankfurt (eu-central-1) als Standard. Hetzner, OVHcloud, IONOS oder Bring-Your-Own-Cloud. AVV nach Art. 28 DSGVO vor Kickoff unterzeichnet.

// Sichere Endpunkte

Verschlüsselte Workstations mit deaktiviertem USB-Schreibzugriff, MDM-verwaltet, biometrische Zugangskontrolle zum Bangalore-Standort, Enterprise-VPN-Tunnel.

// 05

Ersatz & Exit.

// Ersatz

Misfit auf Pilot-Ebene? Ersatz innerhalb von 60 Tagen, kostenfrei.

Passt der Pilot Engineer nicht zum Mandantenkontext, ersetzt niogod™ ihn innerhalb von 60 Tagen ohne Zusatzkosten. Misfit auf Projektleiter-Ebene wird innerhalb von 30 Tagen ersetzt.

// Exit

30 Tage Frist. Code, Dokumentation, Infrastruktur — alles bei Ihnen.

30 Tage Kündigungsfrist. Wissensübergabe inklusive. Keine Exit-Gebühren. Keine deutsche Kündigungsfrist-Exposure. Während der Kündigungsfrist abgeschlossene Werke unterliegen der Standard-Abnahme.
